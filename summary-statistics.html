2  Summary Statistics

WarningEarly draft

This chapter is an early draft and still needs a thorough review. The APIs used in the examples may change as I continue working on the book.

In Chapter 2, Bali et al. (2016) summarize the distribution of stock characteristics within each year, then average those statistics across years. This gives each year’s cross-section equal weight.

2.1 Implementation

2.1.1 Periodic Cross-Sectional Summary Statistics

The methodologies sample (Bali et al. 2016, sec. 1.1) covers US common stocks at each December 31 from 1988 through 2012. I take the December value of the 12-month daily beta from Chapter 8. It uses all available daily excess returns in the calendar year and requires at least 200 matched observations.

import polars as pl

from eap_pl import build_annual_panel, load_annual_betas

annual_beta = load_annual_betas().collect()

For each year, compute the statistics across the stocks with a beta. I use the sample standard deviation, bias-adjusted skewness and excess kurtosis, and linearly interpolated percentiles. The count is the number of available values in that cross-section.

def cross_section(variable):
    x = pl.col(variable)
    return [
        x.mean().alias("Mean"),
        x.std().alias("SD"),
        x.skew(bias=False).alias("Skew"),
        x.kurtosis(fisher=True, bias=False).alias("Kurt."),
        x.min().alias("Min"),
        x.quantile(.05, interpolation="linear").alias("5%"),
        x.quantile(.25, interpolation="linear").alias("25%"),
        x.median().alias("Median"),
        x.quantile(.75, interpolation="linear").alias("75%"),
        x.quantile(.95, interpolation="linear").alias("95%"),
        x.max().alias("Max"),
        x.count().alias("n"),
    ]

annual_stats = (
    annual_beta.group_by("year")
    .agg(cross_section("Beta"))
    .sort("year")
)

annual_stats.rename({"year": "Year"}).eap.show_table()

2.1.2 Average Cross-Sectional Summary Statistics

To describe the typical cross-section, take the mean of each column in Table 2.1. For example, if \(n_t\) stocks have valid betas in year \(t\), their mean is \(\bar{\beta}_t = \sum_{i=1}^{n_t}\widehat{\beta}_{i,t}/n_t\). The table reports \(T^{-1}\sum_{t=1}^{T}\bar{\beta}_t\). A pooled mean would instead give years with more observations more weight. The same two-step procedure applies to the median and other statistics.

average_stats = annual_stats.select(pl.exclude("year").mean())
Code 
average_stats.with_columns(pl.col("n").round().cast(pl.Int64)).eap.show_table()

The annual table also shows that mean beta increased from 0.46 in 1988 to 1.04 in 2012. The time-series average hides that change.

2.2 Presentation and Interpretation

I also summarize year-end market capitalization in millions of dollars, its natural logarithm (size), book-to-market, and the following calendar year’s excess return. build_annual_panel() assembles these observations using start_year and end_year, which default to 1988 and 2012.

The December beta observations already calculated for Table 2.1 define the stock-years in the panel. The helper uses permno and formation year as the join keys. build_sizes() provides December market capitalization and its log, as described in Chapter 9. build_book_to_market() supplies the ratio of prior-year fiscal book equity to prior December market capitalization, as described in Chapter 10. I use its signed ratio, consistent with the negative observations in BEM Table 2.3.

betas = annual_betas.lazy().filter(pl.col("year").is_between(start_year, end_year))
keys = ["permno", "year"]
sizes = build_sizes()
capitalizations = (
    sizes.lazy()
    .filter(pl.col("month").dt.month() == 12)
    .select("permno", year=pl.col("month").dt.year(), MktCap="cap", Size="log_cap")
    .filter(pl.col("year").is_between(start_year, end_year))
)
book_to_market = (
    build_book_to_market(sizes).lazy()
    .filter(pl.col("month").dt.month() == 12)
    .select("permno", year=pl.col("month").dt.year(), BM="bm_raw")
    .filter(pl.col("year").is_between(start_year, end_year))
)

For each stock and holding year, the helper compounds the available monthly returns reported by CRSP. BEM §1.1 does not spell out how its annual returns handle delistings. The helper compounds the monthly risk-free returns separately, requiring 12 observations for the year.

stock_returns = (
    load_parquet("msf", "crsp")
    .filter(
        pl.col("date").is_between(pl.date(start_year + 1, 1, 1), pl.date(end_year, 12, 31)),
        pl.col("ret").is_finite(),
    )
    .with_columns(year=pl.col("date").dt.year())
    .group_by(keys)
    .agg(gross_stock=(1 + pl.col("ret")).product())
)
risk_free = (
    load_parquet("factors_monthly", "ff")
    .with_columns(year=pl.col("date").dt.year())
    .filter(pl.col("year").is_between(start_year + 1, end_year))
    .group_by("year")
    .agg(gross_rf=(1 + pl.col("rf")).product(), n=pl.col("rf").count())
    .filter(pl.col("n") == 12)
)

Subtract the annual risk-free return from the stock return and express the difference in percentage points. Subtracting one from the holding year aligns the return with the characteristics measured the preceding December. For example, the return earned in 1989 is joined to the stock’s 1988 characteristics.

next_year = (
    stock_returns.join(risk_free, on="year", validate="m:1")
    .select(
        "permno",
        year=pl.col("year") - 1,
        excess=100 * (pl.col("gross_stock") - pl.col("gross_rf")),
    )
)

The left joins keep each stock-year in the beta sample even when a characteristic or return is missing. end_year is both the last formation year and the last calendar year included in the return calculations. In the default sample, this leaves the 2012 formation rows with missing next-year returns. The final .collect() returns the assembled panel as a Polars DataFrame.

return (
    betas.join(capitalizations, on=keys, how="left", validate="1:1")
    .join(book_to_market, on=keys, how="left", validate="1:1")
    .join(next_year, on=keys, how="left", validate="1:1")
    .collect()
)
annual_panel = build_annual_panel(annual_betas=annual_beta)

Apply the same summary to each variable separately. This keeps stocks with a beta but no book-to-market ratio in the beta row. The observation count reflects the available data for each variable.

variables = ["Beta", "MktCap", "Size", "BM", "excess"]
all_stats = (
    annual_panel.unpivot(on=variables, index="year", variable_name="Measure")
    .group_by("year", "Measure")
    .agg(cross_section("value"))
    .group_by("Measure")
    .agg(pl.exclude("year", "Measure").mean())
)
Code 
table_2_3 = (
    pl.DataFrame({"Measure": variables}).join(all_stats, on="Measure", maintain_order="left")
    .with_columns(
        pl.col("n").round().cast(pl.Int64),
        pl.col("Measure").replace({
            "MktCap": "Market cap", "BM": "Book-to-market", "excess": "Next-year excess return (%)",
        }),
    )
)
table_2_3.eap.show_table()

Market capitalization has a long right tail. In Table 2.3, the mean is about $2 billion while the median is about $188 million. Taking logs reduces skewness. The annual mean excess return averages 12.40%, and the annual median averages about 0.90%.
