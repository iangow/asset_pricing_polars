1  Data

The examples read local Parquet files through era_pl.load_parquet(). The DATA_DIR setting points to the data root, and each table lives at DATA_DIR/schema/table.parquet. See the repository’s setup instructions to render the book with your own copies. The repository does not include the licensed WRDS data.

1.1 WRDS tables

The table lists the inputs used in this build. The source update date comes from the metadata embedded in each Parquet file, read with db2pq. It is not the sample end date or the date the file was downloaded.

WRDS table Dataset Used for Source updated
crsp.msf_v2 CRSP CIZ Monthly returns and market equity for the sorts and regressions. 2026-02-06
crsp.dsf_v2 CRSP CIZ Daily returns and dollar volume for Amihud illiquidity. 2026-02-06
ff.factors_monthly Fama–French Monthly factors and the risk-free rate for portfolio alphas. 2026-05-23
crsp.msf CRSP legacy (SIZ) Alternate prices and shares outstanding for Table 9.1. 2025-02-08
crsp.msenames CRSP legacy (SIZ) Historical share codes for the Table 9.1 sample. 2025-02-08

Most examples use CRSP’s newer CIZ files. The Table 9.1 replication instead uses legacy CRSP (SIZ), the format available when Bali, Engle, and Murray wrote the book. The local legacy exports are newer than their original snapshot. CIZ is not a drop-in substitute for legacy monthly returns: the two formats differ, for example, in the timing of dividend reinvestment. See CRSP’s comparison of the formats.

1.2 Other input

The Table 9.1 replication also uses the BLS all-items CPI for urban consumers, not seasonally adjusted, from FRED, to express market capitalizations in December 2012 dollars. This file does not come from WRDS.
