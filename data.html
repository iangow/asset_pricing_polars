1  Preliminaries

1.1 Sample

The summary statistics chapter uses BEM’s annual teaching sample of U.S. common stocks at each year-end from 1988 through 2012. The empirical replications use longer monthly samples.

The examples read local Parquet files through era_pl.load_parquet(). The DATA_DIR setting points to the data root, and each table lives at DATA_DIR/schema/table.parquet. See the repository’s setup instructions to render the book with your own copies. The repository does not include the licensed WRDS data.

WRDS tables

The table lists the inputs used in this build. The source update date comes from the metadata embedded in each Parquet file, read with db2pq. It is not the sample end date or the date the file was downloaded.

WRDS table Dataset Used for Source updated
ff.factors_monthly Fama–French Monthly factors and the risk-free rate for betas, alphas, and market checks. 2026-05-23
ff.factors_daily Fama–French Daily market excess returns for Chapter 7 crash checks and daily betas. 2026-06-16
crsp.msf CRSP legacy (SIZ) Legacy prices, shares outstanding, and monthly returns. 2025-02-08
crsp.dsf CRSP legacy (SIZ) Daily stock returns for Chapter 8 beta estimation. 2025-02-08
crsp.msenames CRSP legacy (SIZ) Historical share codes, exchanges, and industries. 2025-02-08
comp.funda Compustat Annual fundamentals for book equity. 2026-06-16
crsp.ccmxpf_lnkused CRSP/Compustat Merged Historical links from Compustat firms to CRSP securities. 2026-02-06
crsp.msedelist CRSP legacy (SIZ) Delisting returns and codes for monthly holding-period returns. 2025-02-08
crsp.msi CRSP legacy (SIZ) CRSP value-weighted index for the market factor comparison. 2025-02-08

The replications use legacy CRSP (SIZ), the format available when Bali, Engle, and Murray wrote the book. The local legacy exports are newer than their original snapshot. The newer CIZ files use different return conventions, including the timing of dividend reinvestment. See CRSP’s comparison of the formats.

Other inputs

The beta, size, and value chapters can export the local Parquet tables eap.betas, eap.sizes, and eap.book_to_market. The annual methods chapters use the December observations from those tables. The render instructions show how to build them.

The CRSP, size, and value chapters use the BLS all-items CPI for urban consumers, not seasonally adjusted, from FRED, to express market capitalizations in December 2012 dollars. This file does not come from WRDS.
