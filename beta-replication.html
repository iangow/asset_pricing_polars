8  Beta

We reconstruct Tables 8.1–8.6 of Bali et al. (2016). The sample consists of CRSP common stocks at the end of each month from June 1963 through November 2012. We use legacy CRSP daily and monthly stock returns and the corresponding Fama–French factors. See Section 1.1.1 for the source vintages.

8.1 Estimating Beta

The CAPM predicts that a stock’s expected excess return is its market beta times the market risk premium, \(\mathbb E[r_i]=\beta_i\mathbb E[MKT]\). To estimate beta, regress the stock’s historical excess return \(r_{i,s}=R_{i,s}-R_{f,s}\) on the market excess return \(MKT_s\), with an intercept. For stock \(i\) at the end of month \(t\),

\[ r_{i,s}=\alpha_i+\beta_i MKT_s+\varepsilon_{i,s}, \qquad \widehat\beta_{i,t} =\frac{\operatorname{Cov}_{s\in W_t}(r_{i,s},MKT_s)} {\operatorname{Var}_{s\in W_t}(MKT_s)}, \]

where \(W_t\) is the estimation window ending in month \(t\). Both moments use the same dates with valid stock and market returns. BEM use the following windows and minimum observation counts (§8.1).

Return frequency Window Minimum observations
Daily 1, 3, 6, 12, or 24 months 15, 50, 100, 200, or 450
Monthly 1, 2, 3, or 5 years 10, 20, 24, or 24

Suppose a stock trades infrequently. Its return may reflect news that first moved the market on a different trading day. BEM consider two adjustments that use a year of daily returns and a 200-observation minimum. Scholes–Williams uses three separate slopes \(b_{-1}\), \(b_0\), and \(b_{+1}\) from regressing \(r_{i,s}\) on \(MKT_{s+k}\) one at a time. Dimson uses the slopes \(\gamma_k\) from one regression with all eleven market returns from \(s-5\) through \(s+5\) as predictors.

\[ \widehat\beta^{SW}_{i,t} =\frac{\widehat b_{-1}+\widehat b_0+\widehat b_{+1}}{1+2\widehat\rho_M}, \qquad \widehat\beta^{D}_{i,t}=\sum_{k=-5}^{5}\widehat\gamma_k, \]

where \(\widehat\rho_M\) is the market return’s first-order autocorrelation over the estimation window. We shift the market series on the trading calendar before joining it to stock returns. A lag can precede the first stock-return date in the window. We omit response dates whose market lead falls after formation and apply the minimum to the remaining complete observations. This keeps all beta inputs observable at formation.

import polars as pl

from era_pl import load_parquet
from eap_pl import load_beta_universe, load_daily_beta_inputs

first = pl.date(1963, 6, 1)
last = pl.date(2012, 11, 1)
last_estimate = last.dt.offset_by("1mo")
keys = ["permno", "month"]

universe = load_beta_universe(first, last_estimate).collect()
names = load_parquet("msenames", "crsp").filter(pl.col("shrcd").is_in([10, 11]))
return (
    names
    .filter(pl.col("namedt") <= last.dt.month_end(), pl.col("nameendt") >= first)
    .with_columns(month=pl.date_ranges(
        pl.max_horizontal(pl.col("namedt").dt.month_start(), first),
        pl.min_horizontal(pl.col("nameendt").dt.month_start(), last),
        interval="1mo",
    ))
    .explode("month")
    .filter(pl.col("month").dt.month_end().is_between("namedt", "nameendt"))
    .select("permno", "month")
    .unique()
)

We screen for common shares at formation using historical share codes 10 and 11. A stock can contribute its earlier returns to the estimation window even if its historical share code changed. We use CRSP’s reported returns for estimation and apply the delisting convention in Section 7.2 to the next-month returns used to evaluate the beta estimates.

monthly_stock = (
    load_parquet("msf", "crsp")
    .filter(pl.col("date").is_between(
        first.dt.offset_by("-59mo"), last_estimate.dt.month_end()
    ))
    .select(
        "permno",
        month=pl.col("date").dt.month_start(),
        ret=pl.col("ret").cast(pl.Float64),
        cap=pl.when((pl.col("altprc") != 0) & (pl.col("shrout") > 0))
        .then(pl.col("altprc").abs() * pl.col("shrout")),
    )
)
monthly_market = load_parquet("factors_monthly", "ff").select(
    pl.col("date").dt.month_start().alias("month"), "mktrf", "rf",
)
monthly_excess = (
    monthly_stock.join(monthly_market, on="month", validate="m:1")
    .select(*keys, "mktrf", retrf=pl.col("ret") - pl.col("rf"))
    .filter(pl.all_horizontal(pl.col("retrf", "mktrf").is_finite()))
)

def beta_slope(stock, market):
    return pl.cov(stock, market) / pl.col(market).var()

For monthly returns, we can apply the covariance-over-variance formula directly. We include the formation dates in the rolling index so a window is evaluated even if the current month’s return is missing. The window is open at its left endpoint and includes the formation month.

monthly_windows = {"1Y": (12, 10), "2Y": (24, 20), "3Y": (36, 24), "5Y": (60, 24)}
daily_windows = {"1M": (1, 15), "3M": (3, 50), "6M": (6, 100),
                 "12M": (12, 200), "24M": (24, 450)}

monthly_returns = (
    universe.lazy()
    .join(monthly_excess, on=keys, how="full", coalesce=True, validate="1:1")
    .sort(keys)
    .collect()
)

def monthly_beta(label, months, minimum):
    return (
        monthly_returns
        .rolling("month", period=f"{months}mo", group_by="permno")
        .agg(
            beta_slope("retrf", "mktrf").alias(label),
            pl.col("retrf").count().alias("n"),
        )
        .select(
            *keys,
            pl.when((pl.col("n") >= minimum) & pl.col(label).is_finite())
            .then(pl.col(label)),
        )
    )

For daily returns, each trading day enters many windows. We sum the regression inputs once per stock and month, then roll those sums across months. For example, the slope uses \(\sum xy-(\sum x)(\sum y)/n\) divided by \(\sum x^2-(\sum x)^2/n\). The adjusted regressions use the same idea with cross-products between market returns at different offsets.

daily_factors, daily_excess = load_daily_beta_inputs(
    first.dt.offset_by("-23mo"), last_estimate.dt.month_end(),
)
offsets = {k: f"mkt_{k + 5}" for k in range(-5, 6)}
daily_factors = (
    load_parquet("factors_daily", "ff")
    .select("date", "mktrf", "rf")
    .sort("date")
    .with_columns(pl.col("mktrf").shift(-k).alias(name) for k, name in offsets.items())
    .with_columns(month=pl.col("date").dt.month_start())
    .with_columns(days_left=pl.len().over("month") - pl.col("date").cum_count().over("month"))
    .collect()
)
daily_excess = (
    load_parquet("dsf", "crsp")
    .filter(pl.col("date").is_between(first, last))
    .select("permno", "date", "ret")
    .join(daily_factors.lazy(), on="date", validate="m:1")
    .with_columns(retrf=pl.col("ret") - pl.col("rf"))
    .filter(pl.all_horizontal(pl.col("retrf", *offsets.values()).is_finite()))
    .select("permno", "month", "retrf", "days_left", *offsets.values())
)

The tables in this chapter end with November 2012 formation, followed by December 2012 holding returns. We also estimate betas as of December 2012. The export saves all eleven estimates per stock-month to DATA_DIR/eap/betas.parquet. Chapters 9 and 10 read its 12-month daily beta for their monthly analyses. The annual methods chapters estimate their December betas when needed.

8.2 Summary Statistics

Table 8.1 averages monthly cross-sectional statistics. The count is the average number of stocks with an available estimate in a month. For example, the dispersion of the one-month daily beta reflects both differences in stocks’ exposures and estimation noise from short return histories. We use sample standard deviations, bias-adjusted skewness and excess kurtosis, and linearly interpolated quantiles.

beta_long = betas.unpivot(
    on=beta_labels, index=keys, variable_name="measure", value_name="beta",
)
b = pl.col("beta")
summary = (
    beta_long.group_by("measure", "month")
    .agg(
        mean=b.mean(), sd=b.std(), skew=b.skew(bias=False),
        kurt=b.kurtosis(fisher=True, bias=False), min=b.min(),
        p05=b.quantile(.05, interpolation="linear"),
        p25=b.quantile(.25, interpolation="linear"), median=b.median(),
        p75=b.quantile(.75, interpolation="linear"),
        p95=b.quantile(.95, interpolation="linear"), max=b.max(), n=b.count(),
    )
    .group_by("measure")
    .agg(pl.exclude("measure", "month").mean())
)

In our data the five-day lead cutoff reduces coverage by eight stocks per month relative to the 12-month daily beta.

8.3 Correlations

Table 8.2 reports the mean of the monthly correlations. For each pair, we use stocks for which both estimates are available. Winsorize each beta within month at the 0.5th and 99.5th percentiles for Pearson correlations below the diagonal. Use the original values for Spearman rank correlations above the diagonal.

clipped = betas.with_columns(
    pl.col(beta_labels).era.winsorize(prob=0.005, quantile_method="linear").over("month")
)

def mean_correlations(panel, method):
    return (
        panel.group_by("month")
        .agg(
            pl.corr(a, b, method=method).alias(f"{a}:{b}")
            for i, a in enumerate(beta_labels) for b in beta_labels[i + 1:]
        )
        .select(pl.exclude("month").fill_nan(None).mean())
        .row(0, named=True)
    )

pearson = mean_correlations(clipped, "pearson")
spearman = mean_correlations(betas, "spearman")

BEM describe Table 8.2 as monthly in §8.3 and annual in its caption. We use monthly cross-sections, consistent with the discussion and sample construction. Correlations between similar lookbacks can partly reflect the observations shared by the estimation windows.

8.4 Persistence

Table 8.3 compares a stock’s winsorized beta with its beta exactly \(\tau\) calendar months later. We calculate a Pearson correlation across stocks in each month and average over months. We leave cells blank when the stock-return windows overlap. This helps distinguish persistence from the effect of using some of the same returns twice.

def persistence(lag):
    columns = [b for b in beta_labels if window_months[b] <= lag]
    current = clipped.select(*keys, *columns)
    future = current.with_columns(month=pl.col("month").dt.offset_by(f"-{lag}mo"))
    return (
        current.join(future, on=keys, suffix="_future", validate="1:1")
        .group_by("month")
        .agg(pl.corr(b, f"{b}_future").alias(b) for b in columns)
        .select(pl.lit(lag).alias("Lag (months)"), pl.col(columns).fill_nan(None).mean())
    )

persistence_table = pl.concat(
    [persistence(lag) for lag in [1, 3, 6, 12, 24, 36, 48, 60, 120]],
    how="diagonal",
)

The 12-month daily beta has a correlation of 0.63 with its value one year later. A year of monthly returns yields a correlation of 0.20. This difference suggests that, over the same one-year lookback, the daily estimate captures a more stable stock characteristic.

8.5 Beta and Stock Returns

8.5.1 Portfolio Analysis

We form deciles using all eligible stocks with an estimate of the given beta in month \(t\). A stock’s decile is one plus the number of breakpoints its beta exceeds. After forming the groups, we join the next month’s excess return. We keep a holding-period return even if a stock leaves the common-share universe during that month. The value weights use market capitalization measured at formation.

deciles = [str(i) for i in range(1, 11)]
decile = 1 + pl.sum_horizontal(
    (b > b.quantile(i / 10, interpolation="linear")).cast(pl.UInt8)
    for i in range(1, 10)
)
members = (
    beta_long.lazy()
    .filter(pl.col("beta").is_not_null())
    .with_columns(decile=decile.over("measure", "month").cast(pl.String))
    .join(outcomes.lazy(), on=keys, validate="m:1")
)

# Use the same stocks in the numerator and denominator of the weighted return.
has_weight = pl.all_horizontal(pl.col("cap", "excess").is_finite())
cap = pl.col("cap").filter(has_weight)
r = pl.col("excess").filter(has_weight)
portfolios = (
    members.group_by("measure", "holding", "decile")
    .agg(
        beta=pl.col("beta").mean(),
        equal=pl.col("excess").filter(pl.col("excess").is_finite()).mean(),
        value=(cap * r).sum() / cap.sum(),
        market=pl.col("market").drop_nulls().first(),
    )
    .collect()
)

We compute the high-minus-low return each month. Its CAPM alpha is the intercept when that return is regressed on the holding month’s market excess return. For each portfolio, we report returns and alphas in percent per month and use six Newey–West lags for their \(t\)-statistics.

import statspai as sp

decile_values = pl.col("beta", "equal", "value")
spread = (
    portfolios.filter(pl.col("decile").is_in(["1", "10"]))
    .group_by("measure", "holding")
    .agg(
        decile_values.filter(pl.col("decile") == "10").first()
        - decile_values.filter(pl.col("decile") == "1").first()
    )
    .join(outcomes.select("holding", "market").drop_nulls().unique(), on="holding", validate="m:1")
    .with_columns(decile=pl.lit("10–1"))
    .select(portfolios.columns)
)
portfolio_series = pl.concat([portfolios, spread]).sort("holding")

def portfolio_fit(series, outcome):
    mean = sp.regress(f"{outcome} ~ 1", data=series, robust="hac", hac_lags=6, hac_small=True)
    capm = sp.regress(f"{outcome} ~ market", data=series, robust="hac", hac_lags=6, hac_small=True)
    return (
        mean.params["Intercept"], mean.tvalues["Intercept"],
        capm.params["Intercept"], capm.tvalues["Intercept"],
    )

Using 12-month daily betas, the high-minus-low excess return is \(-0.55\%\) per month with equal weights (Table 8.4) and \(-0.05\%\) with value weights (Table 8.5). The direction of the equal-weighted spread runs against the CAPM prediction, and the spread is much smaller when large stocks receive more weight.

8.5.2 Fama–MacBeth Regression Analysis

For each measure of beta, we regress next month’s excess return on beta in each monthly cross-section,

\[ r_{i,t+1}=a_{t+1}+b_{t+1}\widehat\beta_{i,t}+u_{i,t+1}. \]

We use the same winsorization as for the Pearson correlations and apply six Newey–West lags to the monthly coefficient series. The CAPM predicts that the mean slope estimates the market risk premium and the mean intercept is zero.

fm_data = (
    clipped.unpivot(on=beta_labels, index=keys, variable_name="measure", value_name="beta")
    .join(outcomes.select(*keys, "excess"), on=keys, validate="m:1")
    .filter(pl.all_horizontal(pl.col("beta", "excess").is_finite()))
)
fm = {
    b: sp.fama_macbeth(
        "excess ~ beta", data=fm_data.filter(pl.col("measure") == b),
        time="month", lags=6,
    )
    for b in beta_labels
}

In Table 8.6 an increase of one in 12-month daily beta is associated with about 0.27 percentage points lower excess return per month. The mean intercept is 0.97% per month, and the slopes for the betas estimated from monthly returns are all close to zero.
