6  Fama and Macbeth Regression Analysis

WarningEarly draft

This chapter is an early draft and still needs a thorough review. The APIs used in the examples may change as I continue working on the book.

This chapter uses BEM’s methodologies sample from Chapter 2 to illustrate the two steps of a Fama–MacBeth regression. The first step fits a cross-sectional regression in each formation year. The second averages the coefficients across years and estimates their standard errors from the time series of annual coefficients.

import polars as pl

from eap_pl import build_annual_panel

annual_panel = build_annual_panel()

6.1 Implementation

6.1.1 Periodic Cross-Sectional Regressions

Compare three univariate regressions with a regression that includes beta, size, and book-to-market together. The outcome is the next year’s excess return in percent. Following Bali et al. (2016, chap. 6), winsorize the regressors at 0.5% in each year’s regression sample. Use six Newey–West lags when estimating standard errors for the averages.

import statspai as sp

specifications = [["Beta"], ["Size"], ["BM"], ["Beta", "Size", "BM"]]
term_labels = {"BM": "Book-to-market"}
fits = []
for terms in specifications:
    sample = (
        annual_panel.select("year", "excess", *terms).drop_nulls()
        .with_columns(
            pl.col(terms).eap.winsorize(prob=0.005, quantile_method="linear").over("year")
        )
    )
    fits.append(sp.fama_macbeth("excess ~ " + " + ".join(terms),
                               data=sample, time="year", lags=6))
Code 
def periodic_results(fit, terms):
    result = pl.from_pandas(fit.model_info["period_coefs"].reset_index())
    return result.with_columns(
        adj_r2=1 - (1 - pl.col("r2")) * (pl.col("nobs") - 1) / (pl.col("nobs") - len(terms) - 1)
    )

periodic = [periodic_results(fit, terms) for fit, terms in zip(fits, specifications)]
pl.concat([
    frame.with_columns(pl.lit(str(i)).alias("Model"))
    for i, frame in enumerate(periodic, 1)
], how="diagonal").select("Model", pl.exclude("Model")).rename(term_labels).eap.show_table()

rows = [
    [i, term_labels.get(term, term), fit.params[term], fit.std_errors[term],
     fit.tvalues[term], f"{fit.pvalues[term]:.3f}"]
    for i, fit in enumerate(fits, 1) for term in fit.params.index
]
pl.DataFrame(rows, schema=["Model", "Term", "Average", "SE", "t", "p"], orient="row").eap.show_table()

6.2 Interpreting FM Regressions

The ordinary Fama–MacBeth standard error is the standard deviation of the annual slopes divided by the square root of the number of years. For the size slope in the regression with all three characteristics, compare the ordinary \(t\)-statistic with the six-lag Newey–West \(t\)-statistic.

Code 
size_slopes = periodic[-1]["Size"]
ordinary_se = size_slopes.std() / len(size_slopes)**0.5
pl.DataFrame({
    "Standard error": ["Ordinary", "Newey–West (six lags)"],
    "t": [size_slopes.mean() / ordinary_se, fits[-1].tvalues["Size"]],
}).with_columns(pl.col("t").round(2))

6.3 Presenting FM Regressions

Code 
from eap_pl import format_fit

terms = ["Beta", "Size", "BM", "Intercept"]
labels = [term_labels.get(term, term) for term in terms]
columns = {"Term": [*labels, "R²", "Adjusted R²", "n"]}
for i, (fit, frame) in enumerate(zip(fits, periodic), 1):
    columns[f"({i})"] = [
        format_fit(fit, term) if term in fit.params else "" for term in terms
    ] + [f"{frame['r2'].mean():.3f}", f"{frame['adj_r2'].mean():.3f}", f"{frame['nobs'].mean():.0f}"]
pl.DataFrame(columns).eap.show_table()
